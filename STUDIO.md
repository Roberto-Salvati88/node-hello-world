# node-hello-world

1. `npm init -y` crea package.json
2. index.js con `console.log('Hello World')`, poi `node index.js`
3. in package.json: `"start": "node index.js"` → `npm run start`
4. `"watch": "node --watch index.js"` → `npm run watch`, cambio il testo in "Hello Boolean" e il terminale si aggiorna da solo

Domande: cos'è Node (runtime JavaScript basato su V8, fa girare JS fuori dal browser), cos'è npm, a cosa serve package.json.
